# What the game played: the sound effects found in the recorded audio of the PACK run (checks-pack.txt), 2026-10-10.
# The client ran with OpenAL Soft's "wave" backend, so the game's real mixed output went to a WAV file (48 kHz stereo). Nobody listened.
# Method (tools/audio/find_sfx.py): the capture is made mono, 16 kHz; each sound file (at every pitch the code can give it) is slid along it
# and the normalised cross-correlation is computed; r = 1.00 means the capture is exactly that sound at that moment. Sounds that start
# under a louder one are matched on a later part of the file (--skip) and the time printed is still where the sound began.
# Time = seconds into the capture (the sound engine started at 09:37:24). Vanilla explosions: random/explode1-4.ogg of Minecraft 1.20.1.

## The attack alarm (beacon_attacked, 4 s, stereo, played to the player wherever they are)
   75.94, 83.92, 91.98, 99.98, 108.04, 116.04, 124.08, 132.08, 140.12, 148.18, 156.18, 164.22, 172.24, 180.30, 188.30, 196.34, 204.40,
   212.42, 220.44, 228.46, 236.50 s (r up to 1.00): every 8.0 s, as the rule says (ALARM_REPEAT_SECONDS) while the red banner stayed up.
   It sounded through the whole fire-support test because the beacon really was under attack: slimes of the flat world, split into
   smaller ones by the harness's own /kill, hopped into the beacon's 24-block reach (one is next to the beacon in
   pack-attack-warning.png). The harness now removes monsters without killing them; the standalone run checks that no alarm sounds
   before its alarm test.

## Loudness in the capture (RMS / loudest 50 ms)
   barrage blasts 48-59 s: -11.5 / -6.4 dB; Cluster crackle 99-111 s: -13.5 / -7.2 dB (nearly as loud as a barrage for 12 s);
   shockwaves: -11.3 / -6.5 dB; Bunker Buster: -8.9 / -4.2 dB; alarm: -10.7 / -6.7 dB; turning loop (heard from about 25 blocks, the loop carries 32): -33.5 dB.
   The cluster was not "a bit quieter" yet: Minecraft caps a sound's loudness at volume 1 and uses a higher volume only to make it carry
   farther, so the code's 2.5 (against 6 for a shell) changed only its range. The bomblet file is now 6 dB quieter (tools/audio/import_sfx.py).
