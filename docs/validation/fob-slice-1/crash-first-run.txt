Cause: Forge's event bus names the class it generates for a @SubscribeEvent method "<package>.__<simple class name>_<method>_<event simple name>".
Fobs.Events.attack(LivingAttackEvent) and RaidAdaptation.Events.attack(LivingAttackEvent) got the same name; the second handler was given the
first one's class. Fix: Fobs.FobEvents. Guard: FobTest.noTwoEventHandlersShareTheBusGeneratedName.

The same run's FOB GameTests failed 0/8 for a second, separate reason: the test village's villagers had no AI and never claimed the beds,
workstations and bell, and vanilla counts a village only around claimed points of interest. Fix: FobGameTests.occupy.
