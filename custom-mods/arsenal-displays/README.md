# Arsenal Displays

Build a gun room worth showing off. Arsenal Displays adds eleven stands, wall
racks and glass cases for **Timeless and Classics Zero (TaCZ)**, including a
wide heavy-weapon stand for miniguns and other oversized weapons.

## Displays

- Standard and wide floor stands
- Standard and wide wall racks
- Compact pistol stand and compact pistol wall rack
- Small and wide floor glass cases
- Small and wide wall glass cases
- A two-block heavy-weapon stand

The glass cases use smaller weapon rendering with extra space below the receiver
for magazines. Wide cases suit rifles; small cases suit pistols and compact guns.
Unusually large addon weapons or attachments may extend beyond a display.

## How to use

Right-click with a TaCZ gun to insert it. Right-click with another gun to swap
them. Right-click with an empty main hand to retrieve the stored gun.
Your weapon keeps its attachments, ammunition, name and other item data.
Both halves of a wide display interact with the same stored weapon.
Wall displays need a solid wall behind every occupied cell.

Standalone installs craft the displays in a normal crafting table with vanilla
iron, any wooden planks, and glass for the glass cases. Combine two matching
small displays and an iron ingot to make their wide version. Find the recipes
in the recipe book or JEI if installed.

## Requirements

**Minecraft Java 1.20.1 · Forge 47.4+ · TaCZ 1.1.8+**

Install Arsenal Displays and TaCZ on both the client and server. No Create,
JEI, KubeJS or defense-beacon mod is required. This release targets Forge;
Fabric and NeoForge builds are not included.

## Create Arsenal integration

When **Create Arsenal: Defense Beacon** is installed, vanilla display recipes
are disabled automatically. Obtain all eleven displays from **Universal Weapon
Platform → Supplies** instead. Existing racks and stored guns retain their
saved registry IDs when upgrading Create Arsenal from 0.17.0 to 0.18.0.

The furniture is rendered as static block geometry. Only the displayed gun uses
TaCZ's native item rendering; the displays have no block-entity tick loop.
